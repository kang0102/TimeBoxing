# TimeBoxing

## 大型股輪動雷達

`rotation.html` 是 GitHub Pages 的手機看板。GitHub Actions 執行 Python 產生靜態 JSON，無須個人電腦保持開機，也不包含下單或帳戶功能。

- 每日行情：`scripts/update_rotation_data.py`；台北 15:43、20:43 與美股收盤後 06:43 依工作日更新。畫面明列行情日及來源延遲。
- 台股最新 Yahoo Close / Adj Close 缺值時，僅在官方同日日期、最高最低價、前日價格基準及無公司行動全部核對通過後補收盤。歷史還原及成交量沿用 Yahoo，不混用官方成交量。未核對通過不推算報價。
- 一眼摘要：研究波次圖、下一棒候選、數字化等待條件、降級條件；已過熱與仍低於月線者分列，不把所有強股都稱為買點。
- 異常同步：同市場同族群至少 3 檔、80% 行情完整；至少 3 檔且 60% 成員同時放量（1.5 倍）、當日強於大盤、RS5 正且站上 MA20。參與率較此前 20 日增加至少 25 個百分點且超過 2 個歷史標準差，才稱異常。反向条件顯示轉弱；法人配合及背離另列。門檻不是統計顯著性或因果證明。
- 台股 Smart Money 用外資＋投信近 5 日，US CMF20 是量價代理，並非識別機構。同步回測不含法人條件。

### 回測与持續檢驗

`scripts/backtest_rotation.py` 下載約 5 年行情，比較最長持有 5、10、20、60 交易日。固定基準：突破前 20 日高點、量比 1.5、RS5 正、站上 MA20、20 日漲幅 ≤25%、MA20 乖離 ≤15%。收盤訊號到下一開盤才成交；收盤跌破 MA20 到下一開盤退出。最多 5 檔、無槓桿、有現金上限及雙邊成本，期末強制結清另列。排名以 RS20，無訊號時持有現金。

訓練與後段驗證分開；訓練期比較量比 1.2 / 1.5 / 2.0，候選不自動套用。驗證期另並列加入異常同步門檻的結果，未用其結果反覆調同步參數。資料共同缺日時隔開該區間並重新累積 65 個交易日才進入驗證，保留原訓練期；不以補平價格假裝正常交易。目前台股來源缺 2025-08-01，因此實際驗證從 2025-11-07 起，美股期間另列，不能直接比較兩市場報酬。

結果是**目前觀察名單的量價代理規則**，存在事後選股／存活者偏差，不代表整套新聞輪動策略已驗證。台股單邊成本假設 0.3%、美股 0.1%，另列成本加倍。模擬使用分割股數與還原價；漲跌停成交限制、流動性衝擊未完整建模。價格指數基準不含股息，與股票還原價口徑不同。

每週六台北 09:23 的 `backtest-rotation.yml` 在雲端重跑，保留最近 52 次報告摘要。`rotation/observations.json` 保存各市場每日首次發布的訊號、波次與籌碼，最多約 252 個交易日；用於往後真正的前瞻檢验，不倒寫舊觀察。每次策略變更需更新 `rotation/strategy.json` 版本、記錄原因、與舊版對照，不因單次回測較好就自動升級。

```sh
python -m pip install -r rotation/requirements.txt
python -m unittest discover -s tests -p 'test_rotation*.py'
python scripts/update_rotation_data.py
python scripts/backtest_rotation.py
```

研究方法參考：[The Probability of Backtest Overfitting](https://escholarship.org/uc/item/4w1110bb)。目前版本只使用時間分割與固定候選對照，未實作該論文的完整 PBO 評估。
